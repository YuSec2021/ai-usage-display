# 001：修复 Claude Code 旧额度与缺失数据显示

日期：2026-11-11

问题：本地 Claude 状态快照与 Desktop 历史没有新数据时，刷新反复读取旧样本，程序仍将其显示为当前额度。较新的快照缺少某个额度字段时，还可能隐藏另一来源的有效窗口；没有额度快照时，已读到的本地 Token 没有显示在卡片上。

修改 `ClaudeUsageProvider.swift` 与 `ProviderCard.swift`：分别选择两个额度窗口的最新可用来源；超过重置时间的值不再显示，未知重置时间时以样本时间加对应窗口时长作为最长有效期。保留已推断的过去重置时间，避免把过期窗口重新当成未知重置时间。全部额度过期时显示重新采集提示；无额度快照时仍保留本地 Token。

验证：修复当轮 Debug 构建通过，34 项 Swift 测试通过；新增回归覆盖窗口过期、新快照刷新、Desktop 过期、推断重置过期、缺失字段回退和无额度时的 Token 显示。当轮测试通过临时 `.xctestrun` 指定中文；后续由记录 002 将语言固定纳入共享测试 scheme。

限制：刷新只重读本地数据，不向 Claude 请求订阅额度。本机尚无新的真实额度样本，须在 Claude Code 下次响应写入新样本后验证实际更新；未替换已安装应用，也未完成 UI 人工检查。

版本与构建号未修改，仍为 1.2.1（Build 5），尚未发布。
