# 003：液态玻璃界面与模型额度圆环

日期：2026-11-11

需求：将 UI 重构为 macOS 26 液态玻璃风格，支持自定义透明度；以 ChatGPT 图标及外圈代替数字额度，外圈表示 5 小时使用额度。

实现：

- `GlassStyle.swift` 在 macOS 26+ 使用原生 `glassEffect(.clear, in:)`，移除原主题的不透明铺底，统一菜单面板、设置与历史窗口的玻璃背景和卡片。参考 [Apple Liquid Glass 文档](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。
- 设置新增 0–100% 的背景透明度滑块，使用 `AppStorage` 保存并实时生效。文字、图标不随背景淡化；“减少透明度”优先使用实色，旧系统采用兼容材质，保留 macOS 13 最低运行版本。原生 API 的构建需要 Xcode 26+ SDK。
- 菜单栏改用支持模板渲染的 22pt 图标圆环，跟随菜单栏浅深色；Codex 使用原有 ChatGPT SVG，其余模型保留对应图标。圆环从顶部顺时针表示已使用额度，详情卡片以同一规则呈现主圆环和其他额度。
- 明确选择 `kind == short` 且 `durationMinutes == 300` 的有效窗口。没有数据、数据不可用或已过重置时间时，主圆环为虚线；真实 0% 为实线空轨道，100% 为完整圆环。不会将周额度、其他时长或 Token 数量当成 5 小时额度。
- 保留原有模型顺序、最多三个菜单栏模型、拖动排序、Token、重置时间与集成操作。已有“最高用量”模式变为最高 5 小时模型圆环；数字百分比保留在悬停提示与 VoiceOver。启用“减少动态效果”后不播放额度填充动画。
- 删除不再使用的数字菜单标题逻辑；About、README 和变更摘要同步本次行为。

验证：

- `make verify` 通过：4 项流程检查器测试、40 项 Swift 单元测试及构建后版本检查均通过。
- 新增 6 项展示测试，覆盖 5 小时与周额度乱序、非 300 分钟窗口、过期/不可用数据、最高额度模式、透明度边界与无障碍覆盖，以及菜单模板图像的未知/0%/部分/100% 区别。
- arm64 本机构建与测试、`make build ARCH=x86_64 BUILD_DIR=.build/intel-check` 交叉构建均通过。
- 离屏输出并检查 `.build/ui-previews/usage-rings-light.png` 与 `usage-rings-dark.png`：ChatGPT/Claude 图标、圆环方向、各状态、文字与重置说明在浅深色下无截断。

限制：原生界面自动化读取已安装应用持续超时，未能完成实际弹窗/滑块交互、重启后偏好及真实桌面玻璃采样检查；组件布局预览使用隔离的示例数据，不代表真实额度或实时玻璃光学效果。远程 CI 和 Intel 原生运行尚未执行。

版本与构建号保持 1.2.1（Build 5），未发布或替换已安装应用。
