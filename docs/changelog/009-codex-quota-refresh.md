# 009：修复 Codex 重置后的额度缺失

日期：2026-11-12

问题：5 小时窗口重置后，本地会话在下一次对话前没有新额度。刷新只重读文件，圆环过滤过期值后统一显示“暂无数据”，而周额度仍然正常。

修改：通过已安装 Codex 的官方 App Server 只读额度接口主动获取当前额度，准确选择 codex bucket，复用现有圆环与日志 Token 汇总。CLI 不可用、未登录、接口失败或超过 8 秒时回退本地日志。无额度的 token 事件不清除已采集样本；不把缺失百分比当作 0。打开面板立即刷新；过期短窗口明确提示等待 Codex 更新，不伪造当前用量。客户端只创建自有 stdio 子进程，不发起对话、登录、登出或 reset credit 请求，不读取或保存凭证。

验证：make verify 通过（16 项流程测试、47 项功能测试，1 项 GPU 预览按默认设置跳过），git diff --check 通过。假 CLI 验证握手、bucket、旧协议、真实 0%、错误、退出与超时；临时 JSONL 验证官方额度覆盖过期值、无日志、失败回退和跨文件 token-only 事件。真实新客户端返回有效 5 小时与 7 天额度。通用 Release 构建、双架构与签名校验通过，本机应用已备份、替换并正常启动。

限制：主动额度需要已安装且已登录的 Codex CLI 和网络；不可用时依赖本地样本，过期后无法给出当前百分比。Token 仍只汇总本机日志，不能代表其他设备的完整统计。

未验证：最终修复构建的菜单面板核对因 Mac 锁屏受阻；没有绕过锁屏。尚未推送、合并或发布。

本机修复构建版本保持 1.2.2（Build 6），以 About 说明区分；后续合入 main 时由自动发布流程升版。
